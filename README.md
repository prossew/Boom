# База данных заявок на обслуживание программного обеспечения

Приложение Xamarin.Forms для создания, просмотра и удаления заявок на обслуживание программного обеспечения. Данные хранятся локально в SQLite (`mydata.db3`).

## Открытие и запуск

1. Установите Visual Studio 2022 с рабочей нагрузкой «Разработка мобильных приложений на .NET» (Xamarin) и Android SDK.
2. Откройте `AppRequests.sln` в Visual Studio 2022 и дождитесь восстановления NuGet-пакетов. При необходимости выполните **Сборка → Восстановить пакеты NuGet**.
3. Выберите `AppRequests.Android` как запускаемый проект, запустите Android-эмулятор и нажмите **Запуск**.
4. В приложении используйте вкладки **О программе**, **Добавить** и **Посмотреть**. Телефон принимается в российских форматах и сохраняется как 11 цифр с начальной `7`.

## Сборка подписанного APK

1. Выберите конфигурацию **Release** и проект `AppRequests.Android`.
2. Щёлкните проект правой кнопкой мыши и выберите **Архивация**.
3. В окне архивов выберите **Распространение → Специальный**.
4. Создайте хранилище ключей Android, указав псевдоним, пароль, ФИО и код страны `RU`.
5. Завершите мастер подписи и получите подписанный `.apk`.

## Проверки

Тесты моделей SQLite и проверки телефона находятся в `tests/AppRequests.Tests`:

```sh
dotnet test tests/AppRequests.Tests/AppRequests.Tests.csproj
python3 tools/check_project.py
```

Для сборки Android требуется установленная Android/Xamarin toolchain. `AppRequests.iOS` включён как заготовка и не требуется для Android-запуска.
